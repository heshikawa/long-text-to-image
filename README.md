A lightweight browser-based tool for turning long text into clean, shareable images.  
No installation, account, or server upload is required.

> **AI disclosure:** The code for this tool was generated entirely with AI based on my requirements. I tested and adjusted the final result.

## Try it online

**Live demo:** https://heshikawa.github.io/long-text-to-image/

## Features

- Chinese / English interface
- Paste text directly or import a `.txt` file
- Live preview
- 4 paper styles: Gardenia, Night Ink, Old Book, and Mist Blue
- Adjustable font size and line spacing
- Custom page count from 1–50 pages
- Export the full text as one long PNG
- Download the current page as PNG
- Batch export all pages as a ZIP file
- Runs entirely in your browser
- Auto-saves text and layout settings locally in the browser

## How to use

1. Open the [live demo](https://heshikawa.github.io/long-text-to-image/) or open `index.html` in a modern browser.
2. Enter a title and paste your text, or choose **Import TXT**.
3. Adjust the paper style, font size, line spacing, and page count.
4. Preview the result in **Long Image** or **Pages** mode.
5. Export a long PNG, the current page, or all pages as a ZIP.

If the text is too long for a single image, use the paged export instead.

## Privacy

All text processing, image generation, and ZIP creation happen locally in your browser.  
**Your text is not uploaded to a server by this tool.**

To support auto-save, the current title, text, layout settings, and language preference are stored in your browser's `localStorage`.

If you are using a shared or public computer, clear the site's browser data when you are finished.

## Requirements

A modern browser with JavaScript enabled.  
No installation or external dependencies are required.

# 中文

这是一个纯浏览器运行的长文字转图片排版工具，可以把小说、笔记、长文等内容排成适合保存和分享的图片。

无需安装、无需注册，也不需要把文字上传到服务器。工具支持中文 / English 一键切换。

> **AI 生成说明：** 本工具代码由 AI 根据我的需求完整生成，我负责提出需求、测试并调整最终成品。

## 在线使用

**在线版：** https://heshikawa.github.io/long-text-to-image/

## 功能

- 中文 / English 双语界面
- 直接粘贴文字或导入 `.txt` 文件
- 实时预览
- 4 种纸张风格：白栀、夜墨、旧书、雾蓝
- 自由调整字号和行距
- 可设置 1–50 页分页
- 整篇导出为一张长图 PNG
- 单独下载当前页 PNG
- 所有分页一键打包为 ZIP
- 全程在浏览器本地处理
- 自动在浏览器中保存正文和排版设置

## 使用方法

1. 打开[在线版](https://heshikawa.github.io/long-text-to-image/)，或直接用浏览器打开 `index.html`。
2. 输入标题并粘贴正文，也可以点击 **导入 TXT**。
3. 调整纸张风格、字号、行距和分页数量。
4. 在 **长图 / 分页** 两种模式中预览效果。
5. 根据需要导出完整长图、当前页，或批量导出 ZIP。

如果全文过长，超过浏览器可生成的单张图片尺寸，请改用分页导出。

## 隐私说明

所有文字处理、图片生成和 ZIP 打包都在浏览器本地完成。  
**这个工具不会把你的正文上传到服务器。**

为了实现自动保存，当前标题、正文、字号、行距、主题、分页数量和语言偏好会保存在浏览器的 `localStorage` 中。

如果是在公共电脑或与他人共用的设备上使用，结束后建议清除该网页的浏览器站点数据。

## 运行要求
